# SIGMA – Comunicación sin barreras

## Descripción del Proyecto

SIGMA es una propuesta tecnológica orientada a facilitar la comunicación entre personas con discapacidad auditiva y personas que no conocen la lengua de señas, promoviendo la inclusión, accesibilidad y autonomía en la interacción cotidiana.

El proyecto busca reducir las barreras de comunicación mediante una solución digital accesible, intuitiva y fácil de utilizar.

Como parte de su desarrollo, se elaboró una Landing Page que presenta la propuesta de SIGMA, sus objetivos, beneficios, funcionamiento propuesto y compromiso con la comunicación inclusiva.

Además, se desarrolló una nueva interfaz de pruebas denominada **Probar SIGMA**, que incorpora herramientas de comunicación mediante texto y voz, como parte del avance de la solución tecnológica.

- Personas que no conocen la lengua de señas.

## Principales Características

### Comunicación Inclusiva

Busca facilitar la interacción entre personas sordas y oyentes mediante una propuesta tecnológica orientada a la comunicación accesible.

### Interfaz Accesible

Presenta una interfaz sencilla, intuitiva y organizada para facilitar la navegación y mejorar la experiencia de los usuarios.

### Funcionamiento de SIGMA

Incluye una sección dedicada a explicar la propuesta de funcionamiento de la solución y su enfoque en la comunicación inclusiva.

### Herramientas de Comunicación

La nueva página de pruebas de SIGMA incorpora herramientas orientadas a facilitar la comunicación:

- **Texto a voz:** permite escribir un mensaje y reproducirlo mediante una voz digital.
- **Voz a texto:** permite utilizar el micrófono para reconocer el habla y convertirla en texto.
- **Selección de idioma y voz:** permite configurar las opciones disponibles para la reproducción de voz.
- **Reproducción de voz:** permite escuchar el texto ingresado.
- **Copiar y guardar:** incorpora controles para gestionar los resultados de las herramientas.
- **Limpiar:** permite borrar el contenido de los campos de texto y los resultados correspondientes.

Incorpora imágenes, ilustraciones y videos para explicar los avances, el diseño inclusivo y el compromiso de SIGMA.

Utiliza una identidad visual basada principalmente en los colores azul y turquesa, con elementos gráficos modernos y una organización clara de la información.

## Control de Versiones y Despliegue

El proyecto utiliza Git y GitHub para el control de versiones y la gestión colaborativa del desarrollo.

Se implementó una organización de ramas basada en GitFlow, utilizando las ramas principales `main` y `develop`, además de ramas `feature` para desarrollar nuevas funcionalidades y mejoras.

Asimismo, se configuró GitHub Actions mediante el archivo `deploy.yml`, permitiendo automatizar la publicación del contenido de la carpeta `public` en GitHub Pages cuando se actualiza la rama `main`.

## Estado del Proyecto

SIGMA se encuentra en desarrollo como proyecto académico orientado a promover la accesibilidad y reducir las barreras de comunicación.

Actualmente, cuenta con una Landing Page informativa y una interfaz de pruebas que incorpora herramientas de conversión de texto a voz y reconocimiento de voz a texto.

El desarrollo de las funcionalidades principales de la solución continúa en proceso, con el objetivo de avanzar hacia una herramienta tecnológica que facilite la comunicación inclusiva.
